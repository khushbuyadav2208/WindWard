Backend source integration uses the bundled genuine dataset and does not depend on network. Browser checks use real API data except the explicitly intercepted failure-state test. `artifacts/browser-results.json`, screenshots, `artifacts/python-audit.json` and the demo manifest provide local evidence; generated files are ignored by Git.

One upstream testing-library deprecation warning remains: Starlette's TestClient currently warns about its httpx transport compatibility. Tests pass; the production adapter uses the explicitly pinned httpx client. It is not a runtime application failure.

## Assumptions retained for review

- Default cutoff: 10:00 Europe/London on D−1, configurable and not asserted as a market gate closure.
- January **purchase decisions** by default; January **deliveries** explicitly optional.
- Hourly WINDFOR targets held across their own two half-hours only; labels disclose alignment.
- Publication timestamps approximate availability; actuals may be revised.
- No demand, prices, financial-risk inference or unrelated business datasets.
- P90 is a descriptive historical percentile, not a future confidence interval.
- Public refresh is token-protected; caches and locks are process/instance-local. Serverless persistence is ephemeral.

Do not mark the challenge submission complete until the external rows above have been fulfilled and their actual URLs verified.
